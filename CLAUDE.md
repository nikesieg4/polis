# Arbeitsregeln für dieses Repo

- Änderungen direkt auf `main` committen und pushen, ohne Pull Request und ohne vorher nachzufragen.
- Die Seite ist rein statisch (`index.html`, `style.css`, `app.js`); kein Build-Schritt einführen, damit GitHub Pages und Cloudflare Pages sie ohne Konfiguration ausliefern.
- Oberfläche und Texte auf Deutsch.
